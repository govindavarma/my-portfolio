# Installation & Setup

Clone the repository:

```bash
git clone https://github.com/govindavarma/portfolio.git
```

Navigate into the project:

```bash
cd portfolio
```

Run locally:

```bash
open index.html
```

Or simply open `index.html` in your browser.
